# Working on this repository

- Run `npm test` before committing (it takes about 15 minutes; `TEST_FILTER=<part of a test name>
  node tests/sim.test.js` runs a subset).
- After each piece of work: commit, push, open a pull request and merge it.
- Document every new problem you find in `Known_Issues.md` (a row in the status table, and a
  short explanation if it needs one), whether or not you fix it. Keep the README's
  *Approximations and known limits* in step with what the simulation actually does.
